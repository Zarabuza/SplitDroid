Сбер, Госуслуги и другие российские приложения исключаются из VPN и идут напрямую. Android допускает только один VPN — отключите коммерческий перед запуском.

Работает · банки вне VPN

Один переключатель. Честный обход для банков.

На Android нельзя держать два VPN сразу. SplitDroid сам становится VPN и выводит российские приложения из туннеля.

01

Отключаете другой VPN

Коммерческий VPN должен быть выключен — иначе система не даст поднять второй туннель.

02

Запускаете туннель

Один тап. Сбер, Госуслуги и другие из списка исключаются из VPN и ходят напрямую.

03

Пользуетесь банками

Российские приложения видят обычную сеть без TRANSPORT_VPN. DNS для остальных — раздельный.
